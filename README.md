# FUTURE_DS_3
Task 3: Marketing Funnel & Conversion Performance Analysis

Overview

This project analyzes marketing funnel data to understand how visitors become leads and customers. It identifies conversion rates and drop-offs at each stage.

Objectives

- Calculate visitor-to-lead conversion rate.
- Calculate lead-to-customer conversion rate.
- Calculate overall conversion rate.
- Compare marketing channels.
- Identify funnel drop-offs.
- Suggest improvements to marketing performance.

Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

Key Metrics

- Visitor-to-Lead Conversion Rate: (Leads / Visitors) × 100
- Lead-to-Customer Conversion Rate: (Customers / Leads) × 100
- Overall Conversion Rate: (Customers / Visitors) × 100
